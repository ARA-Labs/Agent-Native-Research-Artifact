# Common collective failure and budget policy

Load these identical controls in every collective condition, even when no component is installed.
The immutable run configuration pins admitted actors/roles, coordinator, source identities,
common shared path, equal total per-actor allocation, component set, whole-round cadence/expiry,
maximum rounds and registered failures. These are proposed design parameters, not empirical
thresholds. Never change them after observing results or silently add budget, agents or advice.

All coordination reasoning, prompts, publication, synchronization, retries/recovery and merging
belong to the **same total allocation** as research. Reservations account for that allocation;
they do not provide extra compute. Record actual transport and reasoning cost in the external
consumer. The bounded standalone utility uses explicit protocol-allocation units for deterministic
accounting, including one coordination unit per request lifecycle; that is not a measured token,
CPU or experimental budget and cannot establish resource/performance equivalence. External plan15
must bind the same total real compute budget in every condition before scored experiments.
No network/LLM call or extra agent is permitted inside ara or the standalone coordinator.

When intentions are installed, refresh the committed common snapshot before each work-selection
boundary, after every action result, before publishing, and immediately before budget-consuming
execution. Record its sequence/round with the choice. Publication must acknowledge a durable
sequence before execution. A CAS mismatch forces refresh and explicit reconsideration; never
silently overwrite or invisibly retry a changed scientific action. A lost acknowledgment makes
the publication uncertain: recover the **same request identity and digest** before starting work;
never issue a fresh request to duplicate it. Transport receipt recovery is not a new research
procedure or permission for automatic semantic retries.

Unavailable, missing, corrupt, stale/unrecoverable or wrong-run common-channel data is not an
empty intention list. Default: **pause budget-consuming collective work** until an authoritative
refresh/recovery succeeds, or the pre-registered failure policy closes the actor/round/run.
Record the failed refresh logical round/sequence, actual failure time if the consumer has it,
request identity, diagnostic, budget used and interrupted run. Keep every original record.
A consumer cannot proceed by disabling synchronization or reading a private replicated file.

Only the coordinator advances logical rounds and event sequences. A round ends when every
admitted actor finishes its allotted action/turn or registered failure closes it. Registered
failure reasons are `actor-unavailable`, `channel-unavailable`, `budget-exhausted`; the coordinator
records target/reason and optional run closure. Unknown failures require explicit run closure
or a new reviewed policy, not a hidden success. Fresh planned/active intentions expire when the
coordinator round **exceeds** `expires_after_round` without refresh. Expired owners cannot reserve
work forever; retain expired history and disclose stale context rather than treating it as
active research or erasing it. Old run records never seed a new community's active work.

Plain collective controls have no invisible shared snapshot. Frontier-only can inspect local
facts without pretending intentions are installed. Intentions-only cannot claim a combined
frontier intervention. Common role and budget failures still apply to all arms. Offline ara
reads/writes/checks/merges stay usable independently of channel availability; that does not permit
budget-consuming collective execution to violate the registered pause. The standalone outage
smoke distinguishes offline command availability from paused shared execution.

On budget exhaustion, stop execution and record the registered failure/closure; do not borrow
another actor's allocation or add an advisor. On knowledge merge conflict, preserve full competing
bodies, source identities, evidence and history, report unresolved refs, and defer to the normal
researcher/integration-PM adjudication rule. No component auto-promotes, suppresses uncertainty,
selects scientific conclusions or turns a completed intention into proof of success.
