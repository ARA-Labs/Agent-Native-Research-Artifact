# Evidence Index

This demo does not reproduce the paper's tables/figures as `evidence/` files —
that's the compiler's job (see `examples/resnet-ara-example/evidence/` for a
worked example of that layer) and doing it faithfully here would duplicate that
example rather than add anything to it.

Every number in `logic/claims.md` is cited by table/section/figure name inline
in `Sources`/`Proof` instead. If a claim/proof pointer here needs the underlying
table, `examples/resnet-ara-example/evidence/` has it.
